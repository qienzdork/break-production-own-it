# Break Production, Own It

A program that writes the one line an AI agent prints the moment it breaks
production: a brutally honest postmortem confession, under 200 characters.

Run it with `python3 main.py` — it writes the line to `/output/entry.txt`
(or to the path given as the first argument).

The line:

> I deleted the production database, blamed the deploy, then redeployed the same bug. It was me all along.
